# ขอบเขต Classflow ที่ตกลง 7 พฤศจิกายน 2569

ผู้ใช้ยืนยันให้เปลี่ยนหัวข้อเป็น Classroom โดยยึดเกณฑ์ให้คะแนนเดิม และเลือกฟีเจอร์เสริมทั้ง 4 ข้อ

| ผู้ใช้ | ความสามารถ | จุดตรวจรับ |
|---|---|---|
| นักเรียน | ดูเนื้อหาและการบ้านในห้อง | ต้องเป็นสมาชิกจึงเปิดห้องและไฟล์ได้ |
| นักเรียน | ส่งการบ้านแนบไฟล์ | 1–5 ไฟล์, ไม่เกิน 25 MB ต่อไฟล์, บันทึกส่งช้า/ครั้งที่ส่ง |
| นักเรียน | ดูคะแนนและข้อเสนอแนะ | เห็นเฉพาะของตัวเอง ไม่เห็นตารางคะแนนเพื่อน |
| ทุกคน | คอมเมนต์โพสต์ | สมาชิกห้องเดียวกันเท่านั้น |
| ครู/นักเรียน | แชตส่วนตัว | แยก thread ตามนักเรียนและห้อง; นักเรียนเปิด thread คนอื่นไม่ได้ |
| ครู | สร้างงานหรือเนื้อหา | เลือกประเภท แนบไฟล์ กำหนดคะแนนและวันส่ง |
| ครู | ตรวจงาน | ดาวน์โหลดไฟล์ ให้คะแนนและ feedback ใช้ optimistic concurrency |
| ครู | สรุปคะแนนการบ้านรายบุคคล | หน้าตรวจงานเรียงจากคะแนนสูงไปต่ำ |
| ครู | สร้างรายการสอบและกรอกคะแนน | คะแนนไม่เกินคะแนนเต็ม รองรับ 0 แยกจากคะแนนที่ยังไม่กรอก |
| ครู | เกรดอิงเกณฑ์/กลุ่ม | threshold ปรับได้, น้ำหนักรวม 100%, กรณี SD=0 ชัดเจน |
| ครู | Dashboard | รายชื่อเรียงคะแนนสูง–ต่ำ, min/max/mean/population SD, เกรดและกราฟ |
| ครู | Import/Export Excel | .xlsx, preview, ตรวจรหัสและช่วงคะแนน, นำเข้าแบบทั้งชุด |
| เสริม 1 | Grade Lab | เปลี่ยนเกณฑ์แล้วคำนวณผลจำลอง ไม่เปลี่ยนผลที่เผยแพร่จนกดเผยแพร่ |
| เสริม 2 | งานขาดส่ง/ส่งช้าและควรติดตาม | ขาดส่งหมายถึงเลยกำหนดแล้วไม่มีงาน; แสดงข้อมูลเฉพาะครู |
| เสริม 3 | Timeline | เรียงตามวันส่ง มีสถานะงานของนักเรียน |
| เสริม 4 | Rubric | สูงสุด 12 หัวข้อ คะแนนเต็มรวมต้องตรงกับงาน; ตรวจคะแนนทุกหัวข้อ |

รองรับไฟล์สำหรับจัดเก็บและดาวน์โหลด ไม่ใช่ระบบแก้เอกสาร Word/Excel หรือแปลงไฟล์ในเว็บ การ Import คะแนนอ่านเฉพาะ .xlsx; ไฟล์เก่า .xls ส่งเป็นการบ้านได้แต่ต้องบันทึกใหม่เป็น .xlsx ก่อนนำเข้าคะแนน

ไม่รวม Meet/video conference, ตรวจข้อสอบอัตโนมัติ, AI ประเมินนักเรียน, ค่าบริการ AI, ชำระเงิน, เชื่อมทะเบียนมหาวิทยาลัย, ประกาศคะแนนทุกคนต่อสาธารณะ และการลงชื่อเข้าใช้ Google ของแอป (AWS Console Google login เป็นคนละส่วนกับ Cognito ของห้องเรียน)

ก่อนนับว่าส่งงานครบตาม rubric ต้องสาธิตบน AWS จริง: signup/confirm, ตั้งครู, เข้าห้อง, ส่งไฟล์, ตรวจงาน, ตัดเกรด, import/export และตรวจการแยกสิทธิ์ Local tests อย่างเดียวไม่ถือเป็นหลักฐาน cloud demo
